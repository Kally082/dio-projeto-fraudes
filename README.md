# dio-projeto-fraudes

Este projeto apresenta uma análise exploratória e executiva para a detecção de fraudes financeiras. A jornada analítica inclui a avaliação do desbalanceamento de dados (Proporção e Distribuição de Classes), o comportamento dos clientes através da distribuição temporal e de valores transacionados, além da mensuração de performance do modelo via Curvas ROC e Precision-Recall.

### 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Manipulação de Dados:** `pandas`, `numpy`
* **Visualização:** `matplotlib`, `seaborn`
* **Machine Learning:** `scikit-learn`, `xgboost`
* **Tratamento de Desbalanceamento & Explicabilidade:** `imblearn` (SMOTE/Undersampling), `shap`
